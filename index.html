02 / VIDEO

Video Production Workspace Demo

Explore five production stages, search and filters, task progress, synthetic file versions and a pinned current deliverable.

Source-project technology context

Vanilla HTML, CSS, JavaScript and IndexedDB.

This newly authored static demo uses HTML, CSS and JavaScript with memory-only state. It does not use IndexedDB, real files or folder permissions.

What this demo does and doesn’t do

Try it safely

  • Search and filter fictional projects
  • Simulate a contract approval
  • Toggle sample tasks and production stages
  • Pin a synthetic file version as the current deliverable
  • Reset everything to the original demo snapshot

Deliberate boundaries

  • No backend, authentication or real approvals
  • No upload, file picker or folder access
  • No analytics, third-party dependencies or app data requests
  • No persistence, production guarantees or client-delivery claims
  • No license grant is included
